# s6

Установщик кладёт сервис в `/etc/s6/sv/<name>/` (`type`, `run`, `finish`).
Дальше всё зависит от того, как у тебя собран набор сервисов.

## Artix s6

```bash
sudo touch /etc/s6/adminsv/default/contents.d/amneziavpn
sudo s6-rc-compile /etc/s6/rc/compiled /etc/s6/sv
sudo s6-rc-update /etc/s6/rc/compiled
sudo s6-rc -u change amneziavpn
```

`install.sh` пытается сделать это сам, но если структура другая — выполни
команды вручную.

## Проверка

```bash
sudo s6-rc -a list | grep amnezia
sudo s6-svstat /run/service/amneziavpn
```

## Логи

`run` пишет в stdout. Чтобы получить логи, добавь producer:

```bash
mkdir -p /etc/s6/sv/amneziavpn/log
cat > /etc/s6/sv/amneziavpn/log/run <<'EOF'
#!/bin/sh
exec s6-log -b n20 s1000000 /var/log/AmneziaVPN/s6-amneziavpn
EOF
chmod +x /etc/s6/sv/amneziavpn/log/run
```

И пересобери набор.
